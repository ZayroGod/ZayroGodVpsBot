# 🚀 VantixHost VPS Manager Bot

A simple Discord bot to manage VPS connections without Docker or Proxmox.

## ✨ Features
- ✅ No Docker Required
- ✅ No Proxmox Required
- ✅ Create VPS entries with SSH/tmate links
- ✅ DM users with credentials
- ✅ List, View, Delete VPS
- ✅ Regenerate SSH credentials
- ✅ Start/Stop VPS status
- ✅ Persistent JSON storage
